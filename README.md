# Telegram Poetry Bot

Минимальный Telegram-бот: отвечает коротким русским стишком на каждое входящее сообщение, включая команды и сообщения с медиа. Сами сообщения бот не сохраняет и не пересылает.

## Запуск

1. Создайте бота через [@BotFather](https://t.me/BotFather) и скопируйте выданный токен.
2. Установите Python 3.10 или новее.
3. Установите зависимости и задайте токен через переменную окружения:

```bash
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\\Scripts\\activate
pip install -r requirements.txt
export TELEGRAM_BOT_TOKEN="ваш_токен"  # PowerShell: $env:TELEGRAM_BOT_TOKEN="ваш_токен"
python main.py
```

Оставьте процесс запущенным: бот получает сообщения через long polling. Не публикуйте токен и не добавляйте его в Git.

## Настройка чата

В личной переписке бот отвечает на каждое сообщение. В группах Telegram может скрывать сообщения от бота из-за режима приватности; для ответа на все сообщения настройте privacy mode у BotFather или используйте личный чат.
